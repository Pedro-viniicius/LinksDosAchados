Desde 2026-11-03 o produto se chama **Etiqueta** (`<title>` e `<h1>` do `index.html`). A mesma palavra também nomeia a cor de acento da identidade visual (token `--etiqueta`, "botão Etiqueta" nas specs) e a etiqueta de afiliado do Mercado Livre (`achadosmenicas`, na "Regra do dono" do `CLAUDE.md`). O `README.md` (rastreado, uma linha só) e o repo do GitHub se chamam `LinksDosAchados`.

**Why:** numa delegação, "use Etiqueta" ou "a etiqueta" pode significar a marca, a cor ou o afiliado.
**How to apply:** quando uma spec ou um pedido disser "Etiqueta", confirme pelo contexto (token CSS, texto de marca ou link `meli.la`) antes de apontar um achado. Se o `CLAUDE.md` ganhar uma nota de desambiguação, confira se ela ainda bate.
