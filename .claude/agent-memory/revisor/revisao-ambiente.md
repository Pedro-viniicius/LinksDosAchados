O projeto virou repositório git no commit `309bb89` (redesenho, 2026-11-03): use `git diff HEAD` e `git status`. `docs/produto/planos/` e `testes/` podem estar sem rastreio; leia-os direto.
O servidor em 8765 roda no `achadinhos.db` REAL: só GET (`curl localhost:8765/api/items`); nunca POST/PATCH/PUT/DELETE nem `/api/fetch`.

**Páginas de teste (`testes/*.test.html`):** o comando do plano com `--virtual-time-budget` (30000 até 3000000) parou em `RESULTADO: PENDENTE` depois de 5 a 8 testes, em cerca de 1,5 s reais (Chrome 156, 2026-11-03). Em tempo real, pelo protocolo de depuração via `--remote-debugging-pipe` (script Python só com a stdlib: fd 3 e 4, JSON terminado em `\0`, `Target.createTarget`, `Target.attachToTarget` com `flatten`, e `Runtime.evaluate` em `#saida` a cada 1 s), a suíte inteira roda em cerca de 2 s. Confira se o comando registrado no `CLAUDE.md` chega mesmo a `RESULTADO: OK`. Desde a rodada 2 de copiar-imagem, o runner do projeto é `node testes/rodar.mjs <nome>` (precisa do Node 22 ou mais novo, por causa do `WebSocket` global; a máquina tem o v22.23.0). Ele sai com código 0 só quando o resultado é OK.

**Servidor próprio para teste dinâmico (desde blindar-servidor, 2026-11-03):** faça a cópia do banco com backup (o banco está em WAL), a partir de `file:achadinhos.db?mode=ro`. A máquina não tem o CLI `sqlite3`: use `python3 -I -c "import sqlite3,sys; a=sqlite3.connect('file:achadinhos.db?mode=ro',uri=True); b=sqlite3.connect(sys.argv[1]); a.backup(b)" <cópia>`. Com banco vazio, `rodar.mjs copiar-imagem` falha na "preparação" (espera itens), o que não indica regressão. Suba com `ACHADINHOS_DB=<cópia> ACHADINHOS_PORTA=<porta livre> python3 -u servidor.py`, guarde o PID e mate só ele. **Pegadinha do PID (2026-11-03):** em `(cd X && python3 servidor.py) & P=$!`, o `$!` é o do subshell; o `kill $P` não mata o python, que segue ouvindo a porta, e o próximo servidor na mesma porta falha no bind sem você notar (os pedidos vão para o servidor velho, com outro banco). Use `exec python3 ...` dentro do subshell, porta nova a cada servidor, e confira com `ss -ltnp` no fim (em 2026-11-04, `( export ...; exec python3 ...) > log &` ainda deu um `$!` que não era o do python, que tinha PID+1: mate pelo `pid=` do `ss -ltnp` depois de conferir o `ACHADINHOS_DB` no `/proc/<pid>/environ`) (porta ocupada por outro agente: veja `ACHADINHOS_DB` em `/proc/<pid>/environ` e não mate). Não dê ao script do scratchpad nome de módulo da stdlib (`http.py` quebrou o `import http.client`). As suítes do servidor rodam com `python3 testes/test_servidor.py` e `python3 testes/test_servidor_qa.py`. Suba o servidor próprio com `http_proxy` e `https_proxy` apontando para `http://127.0.0.1:9` (proxy morto): o `/api/fetch` dá 502 sem acessar a rede. O servidor agora só serve `/`, `/index.html` e `/testes/*.test.html` (mais a guarda de Host e Origin). Nos testes de origem, confira se eles mandam os cabeçalhos que o Chrome manda de verdade (`Sec-Fetch-Site: cross-site` junto com `Origin`).

**Scripts de dado (desde eletronicos-e-coleta-ml, 2026-11-03):** `migrar_categorias.py` e `coletar_amazon.py` importam `servidor`, então `ACHADINHOS_DB` (e `ACHADINHOS_FEITOS` no coletor) tem que estar no ambiente antes. Prove a migração numa cópia com o seu servidor no ar: `--dry-run`, execução, GET, segunda execução e `--restaurar`. Compare linha a linha com uma segunda cópia (CA2) e o backup com o estado anterior. No banco real, o script pede "sim" ou `--sim`: nunca passe. O `--dry-run` em `mode=ro` cria `-wal`/`-shm` numa cópia parada, o que não é gravação. Para limpar o scratchpad, use um diretório novo: o `rm -rf $VAR/*` é bloqueado. O `classificar_lista.py` (disparo-automatico, etapa 6) segue o mesmo roteiro: cópia, `migrar_categorias.py --sim` na cópia, guarde uma segunda cópia "migrada", `--dry-run`, execução com o servidor próprio no ar, segunda execução, comparação linha a linha e `--restaurar` pelo comando impresso (rodado com `env -u ACHADINHOS_DB -u ACHADINHOS_PORTA` e de outra pasta). Depois rode `PORTA=<p> node testes/rodar.mjs abas` nas duas cópias.
O `--desfazer` dele (rodada 2) volta `cat`/`busca`, mas não o `atualizado_em`. Todo script de dado que grava `atualizado_em` mexe na ordem `recentes` do disparo (`atualizado_em` decrescente): confira esse efeito em toda reclassificação.
**Pegadinha:** com `http_proxy` exportado no shell, o `curl` também usa o proxy morto e devolve vazio. Use `curl --noproxy '*'`, SEMPRE com aspas. Em 2026-11-03, um `--noproxy *` sem aspas, rodado na raiz do projeto, foi expandido para os nomes de arquivo. O curl tratou `README.md` e `*.py` como hosts e mandou os corpos de PUT e POST para servidores externos (por sorte, só dado fictício). Prefira um cliente `http.client` no scratchpad (`Host: localhost:<p>`), rodado sem `-I` se ele importar um módulo vizinho.

**Base para comparar (2026-11-04):** `git archive <commit> | tar -x -C <scratchpad>/base` dá o código antigo sem tocar no `.git`. Rode o mesmo teste lá para separar regressão de instabilidade. Suíte `_qa` vermelha num arquivo que o dev não mexeu: o qa pode estar editando. Rode de novo antes de relatar (o `test_genero_qa` passou de 22 falhas para OK em minutos). Exporte `TMPDIR=<scratchpad>/tmp`, porque o `/tmp` tem pouca cota. **Exceção (2026-11-07):** com esse `TMPDIR`, o `node testes/rodar.mjs` falha com "Chrome não abriu a porta de depuração" (o perfil do Chrome vai para lá). Rode o runner sem `TMPDIR`.

**Why:** gravar ou coletar mexe em dado real ou acessa a Amazon. E um comando de teste que nunca termina parece "pendente", não "falhou".
**How to apply:** para medir layout, copie o `index.html` para o scratchpad, troque `const api` por um stub com itens falsos, troque `:hover` por `.h` para medir a cascata e meça com `--dump-dom`. Abaixo de 500 px, o headless não reduz a janela: use uma moldura com `<iframe>` de 320 e 375 px e `--allow-file-access-from-files`, ou (mais simples, 2026-11-03) um script Node via CDP com `Emulation.setDeviceMetricsOverride` (320/375/1280) e `Emulation.setEmulatedMedia` (claro/escuro) contra o servidor próprio. O script `medir.mjs` do revisor-genero/front faz isso. Um `<pre>` de medida com linhas longas gera rolagem horizontal falsa, então meça `scrollWidth` antes de inseri-lo. Ver [[padroes-ui-designer]].
