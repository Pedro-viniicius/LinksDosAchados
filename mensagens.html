Mensagens Amazon

Coleta pelo seu navegador (sem captcha):

  1. Arraste este botão para a barra de favoritos: 📥 Pegar dados Amazon
  2. Se arrastar não funcionar: clique em , depois aperte Ctrl+Shift+O (gerenciador de favoritos), clique nos três pontos → Adicionar novo favorito, nome Pegar dados Amazon e no campo URL cole o código (Ctrl+V).
  3. No cartão, clique em Abrir na Amazon. A página do produto abre em outra aba.
  4. Nessa aba, clique no favorito Pegar dados Amazon. Os dados voltam sozinhos para o cartão.

Abre o primeiro pendente; a cada clique no favorito, a mesma aba já pula para o próximo. Para parar, feche a aba.

Campos: {TITULO_PRODUTO} {PRECO_PRODUTO} {PRECO_ANTIGO} {DESCONTO_PRODUTO} {NUMERO_VENDAS} {FRETE} {CUPOM} {LINK}
